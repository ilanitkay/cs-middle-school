מהו משתנה?

משתנה הוא "תיבה" עם שם, שבה שומרים ערך לשימוש מאוחר יותר בתכנית. יוצרים משתנה פשוט על ידי השמה (סימן =):

name = "Emma"
age = 13
height = 1.6

ב-Python אין צורך להצהיר מראש מהו טיפוס המשתנה — הוא נקבע אוטומטית לפי הערך שמשמים לתוכו: str למחרוזת (טקסט), int למספר שלם, float למספר עשרוני, ו-bool לערכי אמת/שקר.

כללים לשמות משתנים

מקובל לכתוב שמות משתנים באותיות קטנות, ולהפריד בין מילים בקו תחתון, למשל student_grade.

✅ מה מותר בשם משתנה

  • אותיות אנגליות: גדולות או קטנות (A-Z, a-z)
  • ספרות: 0-9 (אבל לא בתחילת השם!)
  • קו תחתון: _ — יכול להיות בכל מקום, כולל בתחילת השם

❌ מה אסור בשם משתנה

  • להתחיל בספרה — למשל 2num אסור
  • רווחים או תווים מיוחדים — כמו - ! ?
  • מילה שמורה — למשל for, if, while, and, or, not, def, class, import, True, False
רשימה מלאה של כל המילים השמורות ב-Python

and, as, assert, break, class, continue, def, del, elif, else, except, finally, for, from, global, if, import, in, is, lambda, nonlocal, not, or, pass, raise, return, try, while, with, yield

לא צריך לשנן את הרשימה — מספיק לדעת שהיא קיימת, ושבמקרה של הודעת שגיאה מוזרה על שם משתנה, כדאי לבדוק שהוא לא בטעות אחת המילים האלה.

קליטת קלט מהמשתמש

ההוראה input() עוצרת את התכנית וממתינה שהמשתמש יקליד משהו במקלדת. חשוב לדעת: input() תמיד מחזירה מחרוזת — גם אם המשתמש הקליד מספר! לכן כדי לקבל מספר שלם צריך לעטוף ב-int(), ולמספר עשרוני ב-float().

name = input("What is your name? ")
age = int(input("How old are you? "))
print("Hello", name, ", next year you'll be", age + 1)

אופרטורים מתמטיים

מלבד ‎+ ‎- ‎* ‎/ הרגילים, בפייתון יש שני אופרטורים שכדאי להכיר טוב, כי הם מופיעים המון בבחינות ובתרגילים:

  • // — חילוק שלם: מחזיר רק את החלק השלם של תוצאת החילוק (מעגל כלפי מטה).
  • % — מודולו (שארית חלוקה): מחזיר את השארית שנשארת מהחילוק.
דוגמה 
number = 17
print(number // 5)   # 3  (החלק השלם של 17/5)
print(number % 5)    # 2  (מה שנשאר מ-17 אחרי 3 חמישיות)

כדי להבין איך בדיוק מגיעים לתוצאות האלה, כדאי לחשוב על זה כמו חילוק "בעמודה" מבית הספר — עם שלם ושארית:

שיטת חישוב מהירה בעצמכם (בלי מחשבון): כדי לחשב 23 % 4 — חפשו את הכפולה הגדולה ביותר של 4 שעדיין לא עוברת את 23 (זו 4×5=20), הפחיתו אותה מהמספר המקורי: 23−20=3. זו התשובה. נסו כעת בעצמכם: כמה שווה 29 % 6? (הכפולה הגדולה ביותר של 6 שלא עוברת את 29 היא 6×4=24, ולכן 29−24=5).

טריק נפוץ מאוד: אפשר להשתמש ב-// וב-% כדי לפרק מספר לספרותיו. למשל, כדי לקבל את ספרת האחדות של מספר תלת-ספרתי נשתמש ב-number % 10, ואת שתי הספרות הראשונות נקבל עם number // 10.

חילוק עם בדיקה

בדיוק כמו שלומדים במתמטיקה לבצע "בדיקת חילוק" (מחלק × מנה + שארית = המספר המקורי), אפשר לגרום ל-Python לבצע את הבדיקה הזו בעצמה — וכך גם לוודא שהבנו נכון את // ו-%:

number = 23
divisor = 4
quotient = number // divisor
remainder = number % divisor
check = divisor * quotient + remainder
print("quotient:", quotient, "remainder:", remainder)
print("check:", check)  # אמור לצאת שוב 23 - זו הבדיקה!

אם check יוצא שווה למספר המקורי — סימן שהחישוב נכון. זו בדיוק אותה בדיקה שעושים "בעמודה" בכתב, רק שכאן Python עושה את זה במקומנו.
