גישה לתו לפי מיקום (אינדקס)

מחרוזת היא בעצם רצף של תווים, ולכל תו יש "מיקום" (אינדקס) המתחיל מ-0 עבור התו הראשון. אפשר לגשת גם מהסוף, עם אינדקסים שליליים: 1- הוא התו האחרון, 2- הוא לפני האחרון וכן הלאה.

דוגמה 
v = "Water"
print(v[0])   # W
print(v[2])   # t
print(v[-1])  # r (התו האחרון)

חיתוך מחרוזת — slicing

אפשר לחתוך "פרוסה" מהמחרוזת בעזרת התחביר string[start:end:step]: מהאינדקס ההתחלתי (כולל) ועד אינדקס הסיום (לא כולל), עם קפיצה אופציונלית. השמטת כל אחד מהם משאירה את ברירת המחדל (מההתחלה / עד הסוף / קפיצה של 1).

v = "Water"
print(v[1:3])    # at
print(v[:2])     # Wa   (מההתחלה עד אינדקס 2, לא כולל)
print(v[2:])     # ter  (מאינדקס 2 עד הסוף)
print(v[::-1])   # retaW  (שלב שלילי - הופך את המחרוזת!)

הטריק v[::-1] הוא הדרך הקלה ביותר להפוך מחרוזת: משאירים start ו-end ריקים (כל המחרוזת) וקובעים קפיצה של 1-, כלומר "מהסוף להתחלה".

אופרטורים על מחרוזות

האופרטורים + ו-* מקבלים משמעות מיוחדת כשמפעילים אותם על מחרוזות: + משרשר (מחבר) שתי מחרוזות, ו-* משכפל מחרוזת מספר פעמים.

first = "Hello "
second = "World"
print(first + second)   # Hello World
print("ab" * 3)         # ababab

האופרטור in בודק אם תו או תת-מחרוזת נמצאים בתוך מחרוזת אחרת, ומחזיר True או False:

print("y" in "python")   # True

פעולות מובנות שימושיות

למחרוזת יש הרבה פעולות ("מתודות") מובנות. אלה החשובות ביותר:

s = "Programming in Python"

len(s)                # 22   - אורך המחרוזת
s.upper()             # PROGRAMMING IN PYTHON
s.lower()             # programming in python
s.find("in")          # 12   - אינדקס ההופעה הראשונה, או 1- אם לא נמצא
s.count("r")          # 2    - כמות ההופעות של r
s.replace("Python", "Java")  # מחליף תת-מחרוזת באחרת
s.startswith("Pro")   # True
s.endswith("n")      # True

שימו לב: כל הפעולות האלה לא משנות את המחרוזת המקורית (מחרוזות ב-Python אינן ניתנות לשינוי) — הן תמיד מחזירות מחרוזת חדשה. לכן אם רוצים לשמור את התוצאה יש להשמים אותה למשתנה: s = s.upper().

בניית מחרוזת חדשה תו-אחר-תו

תבנית נפוצה מאוד: לעבור על מחרוזת קיימת באמצעות לולאה, ולבנות ממנה מחרוזת חדשה תו אחרי תו לתוך משתנה שמתחיל כמחרוזת ריקה:

result = ""
for letter in "hello":
    result = letter + result
print(result)  # olleh

רוצים לבנות מחרוזת חדשה שבה כל תו מהמחרוזת המקורית חוזר פעמיים — למשל "abc" יהפוך ל-"aabbcc". השלימו:

original = "abc"
result = ""
for letter in original:
    result = result + letter ______
print(result)
הצג תשובה 
result = result + letter + letter

אפשר גם לכתוב letter * 2 במקום letter + letter — שני האופרטורים + ו-* עובדים על מחרוזות.
