אופרטורים של השוואה

תנאי בנוי מביטוי בוליאני — ביטוי שערכו תמיד True (אמת) או False (שקר). כדי לבנות ביטוי כזה משתמשים באופרטורי השוואה:

<   קטן מ
<=  קטן או שווה
==  שווה ל (שימו לב: שני סימני שווה!)
>=  גדול או שווה
>   גדול מ
!=  שונה מ

if פשוט, ועם else

אם ברצוננו שקוד מסוים ירוץ רק כשתנאי מתקיים, נשתמש ב-if. אם נרצה גם "מסלול חלופי" למקרה שהתנאי לא מתקיים — נוסיף else.

דוגמה — בדיקת מספר זוגי 
num = int(input("Enter a number: "))
if num % 2 == 0:
    print("even")
else:
    print("odd")

שרשרת תנאים עם elif

כשיש יותר משתי אפשרויות, אפשר לקנן if בתוך else — אבל זה מייצר הזחות רבות ומסובך לקריאה. הפתרון הנקי הוא elif (קיצור של "else if"):

דוגמה — קבלה ללימודים לפי ציון 
grade = int(input("Psychometric score: "))
if grade > 730:
    print("Accepted")
elif grade > 600:
    print("Conditionally accepted")
else:
    print("Not accepted")

ל-Python חשוב הסדר: היא בודקת את התנאים אחד-אחד מלמעלה למטה, ומריצה רק את הבלוק הראשון שמתקיים — כל השאר מדולגים, גם אם היו מתקיימים.

תנאי מקונן (if בתוך if)

לפעמים צריך לבדוק תנאי רק אחרי שתנאי קודם התקיים — אז מכניסים if נוסף בתוך גוף ה-if הראשון:

grade = int(input("Grade: "))
if grade >= 0:
    if grade <= 100:
        print("valid grade")
    else:
        print("invalid grade")
else:
    print("invalid grade")

תנאים מורכבים: and, or, not

כדי לבדוק כמה תנאים יחד באותה שורה, משתמשים במילים and / or / not:

  • and ("וגם") — הביטוי המורכב אמת רק אם שני הביטויים אמת
  • or ("או") — הביטוי המורכב אמת אם לפחות אחד מהביטויים אמת
  • not ("לא") — הופך את הערך של הביטוי: אמת הופך לשקר ולהפך
דוגמה — בדיקת מספר דו-ספרתי 
num = int(input("Enter a number: "))
if num >= 10 and num <= 99:
    print("two digits")
else:
    print("not two digits")

שימו לב לסדר הפעולות: and "חזק" יותר מ-or, כלומר Python מחשבת אותו קודם. לכן בתנאים מורכבים שמשלבים and ו-or יחד, מומלץ מאוד להשתמש בסוגריים כדי להבהיר בדיוק מה רוצים לבדוק — זו אחת הטעויות הנפוצות ביותר במבחנים:

# שני תנאים שנראים דומים אך שונים לגמרי בגלל הסוגריים:
if (a > 5 or b <= 4) and a == b:
    ...

if a > 5 or (b <= 4 and a == b):
    ...

תנאי עם מחרוזות

אפשר גם לבדוק שייכות של תו או מחרוזת בתוך מחרוזת אחרת, בעזרת in ו-not in:

if "y" in "python":
    print("the letter is in the word")

1עקבו אחר הקוד

נתונים המשתנים a = 8, b = 12, c = 0. מה ערכו (True או False) של כל ביטוי בוליאני?

סעיףביטויערך (True/False)
1a >= b or b == c________
2a % 2 == 0 and b // 4 > c________
3a < 0 or (b == c + 12 and a >= c)________
הצג תשובות

1. False or False → False (8>=12 שקר, 12==0 שקר)
2. True and True → True (8%2==0 אמת, 12//4=3 שגדול מ-0)
3. False or (True and True) → True (הסוגריים חושבים ראשונים: 12==0+12 אמת, ו-8>=0 אמת)

2מצאו את הטעות

קטע הקוד הבא נועד להדפיס "Prize!" רק לתלמיד/ה עם ציון מעל 90. אבל נפלה בו טעות לוגית. מהי הטעות, וכיצד יש לתקנה?

grade = int(input("Grade: "))
if grade > 90 or grade <= 100:
    print("Prize!")
else:
    print("No prize")
הצג תשובה

הטעות היא השימוש ב-or במקום and. כרגע כל ציון (למשל 50) מקיים לפחות תנאי אחד (50 <= 100), ולכן תמיד יודפס "Prize!" — טעות נפוצה שנראית "הגיונית" אך הופכת את התנאי לתמיד אמת. התיקון:

if grade > 90 and grade <= 100:
