תנועה ומבוא לגרפיקה — Turtle

⏱ כ-6 שעות לימוד

מה נלמד בפרק הזה

  • לייבא ולהפעיל את ספריית הגרפיקה Turtle
  • ליצור משטח עבודה (מסך) ודמות (צב) שמציירת עליו, ולשלוט בגודלו ובצבעים שלו
  • לזמן פקודות תנועה: קדימה, פנייה בזווית, הרמת/הורדת העט
  • לשלב פקודות תנועה בתוך לולאה כדי לצייר צורות

מהי ספריית Turtle?

Turtle היא ספרייה מובנית ב-Python שמדמה "צב" עם עט הצמוד אליו: כל תזוזה של הצב משאירה קו על המסך. זו דרך מצוינת להתחיל עם גרפיקה, כי אפשר "לחשוב" כמו הצב — לאן פונים, כמה צעדים הולכים.

יצירת משטח עבודה ודמות

import turtle           # טעינת הספרייה

wn = turtle.Screen()      # יצירת חלון (משטח ציור)
player = turtle.Turtle()  # יצירת הצב שיצייר
player.shape("turtle")     # עיצוב הדמות כצורת צב

ארבע השורות האלה הן ה"פתיחה" של כל תכנית Turtle — בלעדיהן שם המשתנה player עדיין לא קיים, והתכנית תיפול בשגיאה. בכל דוגמה בהמשך הפרק, נניח שהשורות האלה כבר רצו לפניה.

בדיוק כמו שבסקראץ' יש למשטח הציור גודל קבוע — גם ב-Turtle יש גודל ברירת מחדל למשטח הציור: 400×300 פיקסלים. הצב מתחיל תמיד במרכז המשטח בדיוק, פונה ימינה. אפשר לשנות את הגודל הזה, וגם לקבוע צבעים:

wn.setup(width=600, height=400)  # קובע גודל מדויק לחלון, בפיקסלים
wn.bgcolor("lightblue")             # צבע הרקע של החלון
player.color("red")                 # צבע הצב והקו שהוא מצייר

פקודות תנועה בסיסיות

הפקודות הנפוצות ביותר: forward(n) מזיזה את הצב n צעדים קדימה, left(angle) ו-right(angle) מסובבות אותו בזווית נתונה (במעלות).

import turtle
player = turtle.Turtle()

player.forward(100)  # 100 צעדים קדימה
player.left(90)     # סיבוב שמאלה ב-90 מעלות
player.forward(50)

turtle.mainloop()      # משאיר את חלון הציור פתוח

ציור צורות באמצעות לולאה

הכוח האמיתי של Turtle מתגלה כשמשלבים אותה עם לולאת for (נכיר לעומק בפרק 5). כדי לצייר ריבוע, למשל, פשוט חוזרים 4 פעמים על "התקדם וסובב 90 מעלות":

דוגמה — ציור ריבוע 
import turtle

wn = turtle.Screen()
player = turtle.Turtle()
player.shape("turtle")

for i in range(4):
    player.forward(80)
    player.left(90)

turtle.mainloop()

שימו לב: כדי לצייר מצולע משוכלל בעל n צלעות, זווית הפנייה בכל פעם היא 360 / n מעלות — כי סכום כל הפניות חייב להשלים מעגל שלם.

שינוי מאפייני הדמות

אפשר גם לשלוט על איך הצב נראה ומתנהג: penup() ו-pendown() מרימים/מורידים את העט (מזיזים בלי לצייר), hideturtle() מסתירה את סמל הצב, ו-color("red") קובעת צבע קו.

שאלות בסגנון בחינות המפמ״ר, מהקל למאתגר. נסו לענות לפני שאתם בודקים את התשובה.

1עקבו אחר הקוד

לפניכם קטע קוד. בלי להריץ אותו — תארו במילים שלכם איזו צורה תצייר הדמות, וכמה פעמים תתבצע כל אחת מהלולאות.

for i in range(3):
    player.forward(70)
    player.left(120)
הצג תשובה

הלולאה תתבצע 3 פעמים. בכל פעם הצב מתקדם 70 צעדים ופונה שמאלה ב-120 מעלות. מכיוון ש-3 × 120 = 360 מעלות (מעגל שלם), הצב יחזור בדיוק לנקודת ההתחלה ולכיוון ההתחלתי — כלומר תצויר משולש שווה-צלעות.

2מה יצייר הצב?

קטע הקוד הבא רץ מנקודת ההתחלה. איזו מהצורות שלפניכם תתקבל על המסך? הקיפו את התשובה הנכונה.

size = 80
for i in range(4):
    for j in range(4):
        player.forward(size)
        player.left(90)
    size = size - 20

4כתבו תוכנית

כתבו תוכנית שמציירת "מדרגות" של 5 שלבים (כמו בצורה ד׳ שבשאלה 2, אך עם 5 שלבים במקום 3). נסו קודם בעצמכם, ורק אז בדקו את התשובה המוצעת.

הצג פתרון אפשרי

wn = turtle.Screen()

for i in range(5):
    player.forward(30)
    player.left(90)
    player.forward(30)
    player.right(90)

turtle.mainloop()

7אתגר

הוסיפו penup() באמצע התכנית ונסו להזיז את הצב למקום חדש בלי לצייר קו, ואז המשיכו לצייר עם pendown().

8פרויקט קטן — ציירו בית

נסו לצייר בית פשוט: ריבוע לגוף הבית, ומשולש לגג מעליו. רמז — אחרי שהריבוע מוכן, סובבו את הצב לזווית המתאימה כדי "לטפס" לפינה העליונה ולהתחיל לצייר את הגג משם.

הצג פתרון אפשרי 
import turtle

wn = turtle.Screen()
player = turtle.Turtle()

# גוף הבית - ריבוע
for i in range(4):
    player.forward(100)
    player.left(90)

# טיפוס לפינה העליונה של הריבוע
player.forward(100)
player.left(30)

# הגג - משולש
for i in range(3):
    player.forward(100)
    player.left(120)

turtle.mainloop()

14כמה פעמים תרוץ הלולאה?

כתבו כמה פעמים תתבצע הלולאה, וכמה מעלות סה"כ יסתובב הצב:
