למה בכלל צריך פרמטרים?

בפרק 1 הכרנו פונקציה בלי פרמטרים — היא תמיד עושה בדיוק אותו דבר בכל קריאה. פרמטר הוא "משבצת קלט" שמאפשרת לפונקציה לקבל מידע מבחוץ ולהתנהג אחרת בהתאם, בלי לשכפל קוד.

דוגמה — פונקציה שמברכת אדם ספציפי 
def greet(name):
    print("Hello,", name, "!")

greet("Emma")   # Hello, Emma !
greet("Alex")   # Hello, Alex !

אפשר להעביר גם כמה פרמטרים, מופרדים בפסיקים — הסדר חשוב! הערך הראשון בקריאה יישלח לפרמטר הראשון בהגדרה, וכן הלאה.

def add(a, b):
    print(a + b)

add(3, 5)   # 8

משתנה מקומי לעומת גלובלי

משתנה שנוצר בתוך פונקציה נקרא משתנה מקומי — הוא קיים רק בזמן ריצת הפונקציה, ולא ניתן לגשת אליו מחוצה לה. משתנה שהוגדר מחוץ לכל הפונקציות נקרא משתנה גלובלי, ואפשר לקרוא את ערכו מכל מקום בתכנית.

אם רוצים שפונקציה תשנה משתנה גלובלי (ולא רק לקרוא את ערכו), צריך להצהיר על כך בתוך הפונקציה במילת המפתח global:

דוגמה 
score = 0  # משתנה גלובלי

def add_point():
    global score
    score = score + 1

add_point()
add_point()
print(score)  # 2

בלי השורה global score, Python הייתה יוצרת בטעות משתנה מקומי חדש בשם score בתוך הפונקציה, וה-score הגלובלי היה נשאר 0 — טעות נפוצה מאוד.

פונקציות עם פרמטרים ו-Turtle

שילוב שימושי מאוד: פונקציה שמציירת צורה, ומקבלת כפרמטר את הגודל שלה — כך אפשר לצייר את אותה צורה בגדלים שונים בלי לשכפל קוד:

import turtle

wn = turtle.Screen()
player = turtle.Turtle()

def draw_square(size):
    for i in range(4):
        player.forward(size)
        player.left(90)

draw_square(50)
draw_square(100)
turtle.mainloop()

מה יודפס בכל שורה כתוצאה מהרצת הקוד הבא?

def describe(name, age):
    print(name, "is", age)

describe("Tom", 14)
describe(13, "Maya")
הצג תשובה 
Tom is 14
13 is Maya

שימו לב לקריאה השנייה: הפרמטרים מועברים לפי סדר, לא לפי משמעות — לכן 13 יישלח ל-name ו-"מאיה" יישלח ל-age, מה שיוצר פלט משונה. זו תזכורת לחשיבות סדר הפרמטרים.

2מצאו את הטעות

הקוד הבא נועד לספור כמה פעמים נקראה הפונקציה, אבל ה-counter נשאר תמיד 0. מהי הטעות?

counter = 0

def log_call():
    counter = counter + 1

log_call()
log_call()
print(counter)
הצג תשובה

בלי global counter בתוך הפונקציה, Python יוצרת משתנה מקומי חדש בשם counter בתוך log_call — וזה בכלל גורם לשגיאת ריצה (ניסיון לקרוא ל-counter המקומי לפני שהוגדר). התיקון: להוסיף global counter כשורה הראשונה בתוך הפונקציה.

10פרויקט קטן — תפריט מחשבון

כתבו 4 פונקציות: add(a, b), subtract(a, b), multiply(a, b), divide(a, b) — כל אחת מקבלת שני מספרים ומדפיסה את התוצאה. אחר כך כתבו תכנית שמציגה למשתמש/ת תפריט (1=חיבור, 2=חיסור, 3=כפל, 4=חילוק), קולטת שני מספרים ובחירה, וקוראת לפונקציה המתאימה.

הצג פתרון אפשרי 
def add(a, b):
    print("Result:", a + b)

def subtract(a, b):
    print("Result:", a - b)

def multiply(a, b):
    print("Result:", a * b)

def divide(a, b):
    print("Result:", a / b)

print("1. Add")
print("2. Subtract")
print("3. Multiply")
print("4. Divide")

choice = int(input("Choose an option (1-4): "))
num1 = int(input("First number: "))
num2 = int(input("Second number: "))

if choice == 1:
    add(num1, num2)
elif choice == 2:
    subtract(num1, num2)
elif choice == 3:
    multiply(num1, num2)
elif choice == 4:
    divide(num1, num2)
