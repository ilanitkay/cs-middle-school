מה זו בעצם תכנית מחשב?

תכנית מחשב היא רשימת הוראות שהמחשב מבצע אחת אחרי השנייה, מלמעלה למטה. ב-Python כותבים כל הוראה בשורה משלה, ובניגוד לשפות רבות אחרות — אין צורך בסוגריים מסולסלים או נקודה-פסיק בסוף שורה. במקום זאת, Python "מבינה" את מבנה התכנית לפי הזחה (הרווח שבתחילת השורה), ולכן חשוב מאוד לשמור על הזחה עקבית.

ההוראה print

ההוראה הראשונה שכל מתכנת/ת לומד/ת היא print — היא מדפיסה טקסט או ערך אל המסך.

דוגמה 
print("Hello, I'm learning Python!")
print("Computer Science")
print("Grade 8")

אפשר להדפיס גם כמה ערכים בהוראת print אחת, כאשר מפרידים ביניהם בפסיק — Python תוסיף רווח בין הערכים באופן אוטומטי:

print("Name:", "Daniel", "Grade:", "8B")
# Output: Name: Daniel Grade: 8B

הערות בקוד

שורה שמתחילה בסימן # היא הערה — Python מתעלמת ממנה לגמרי. הערות משמשות אותנו כדי להסביר לעצמנו (ולאחרים) מה הקוד עושה, בלי להשפיע על ריצת התכנית.

# התכנית הבאה מדפיסה ברכה
print("Good morning!")

פעולות חשבוניות בסיסיות

Python יודעת לבצע חישובים ישירות על מספרים, בלי שצריך שום דבר נוסף — אפשר פשוט לכתוב את החישוב בתוך print:

print(3 + 4)   # 7  (חיבור)
print(10 - 3)  # 7  (חיסור)
print(6 * 5)   # 30  (כפל)
print(10 / 4)  # 2.5  (חילוק)

שימו לב: סימן החילוק ב-Python הוא / (ולא : כמו בכתיב בבית ספר) — והתוצאה שלו תמיד מספר עשרוני (float), גם אם החלוקה יוצאת "עגולה":

print(10 / 2)  # 5.0, ולא 5

עוד שלוש פעולות שכדאי להכיר

מלבד + - * / יש ב-Python עוד שלושה אופרטורים חשבוניים חשובים:

print(10 // 3)  # 3  (חילוק שלם - רק החלק השלם של התוצאה, בלי השארית)
print(10 % 3)   # 1  (מודולו - רק השארית שנשארת מהחילוק)
print(2 ** 3)   # 8  (חזקה - 2 בחזקת 3)

// ו-% נמצאים בשימוש כל כך רב (למשל, לבדוק אם מספר זוגי, או לפרק מספר לספרותיו) שנקדיש להם הסבר מלא ותרגול נפרד בפרק 3.

סדר פעולות

Python פועלת לפי אותם כללי סדר פעולות שמכירים מהמתמטיקה: קודם כפל וחילוק, ורק אחר כך חיבור וחיסור. כדי לשנות את הסדר — בדיוק כמו במתמטיקה — משתמשים בסוגריים:

print(3 + 4 * 2)    # 11  (קודם 4*2=8, ואז 3+8)
print((3 + 4) * 2)  # 14  (הסוגריים מחשבים קודם: 3+4=7, ואז 7*2)

אפשר גם לשלב כמה פעולות בהוראת print אחת, כולל טקסט לצד החישוב:

print("The result is:", 5 + 3 * 2)
# Output: The result is: 11

מבוא לפונקציות

פונקציה היא קבוצת הוראות שאורזים יחד תחת שם אחד, כדי שנוכל להריץ אותן שוב ושוב בקריאה אחת קצרה — במקום להעתיק את אותו קוד כל פעם מחדש. בפרק זה נכיר פונקציה פשוטה: בלי פרמטרים (בלי "קלט" לפונקציה) ובלי ערך מוחזר.

בניית פונקציה מורכבת משני שלבים: קודם מגדירים אותה באמצעות def, ורק אחר כך מזמנים (קוראים ל) אותה — כדי שהיא באמת תרוץ.

דוגמה 
def say_hello():
    print("Welcome to Computer Science class!")

# עד כאן רק הגדרנו את הפונקציה - היא עדיין לא רצה
say_hello()  # עכשיו זימנו אותה, וזה מה שגורם לה לרוץ

שימו לב לשני דברים חשובים: הנקודתיים (:) בסוף שורת ה-def, וההזחה של השורה שבתוך הפונקציה — כל שורה מוזחת שייכת לגוף הפונקציה.

מושגי מפתח

// (חילוק שלם)

% (מודולו)

** (חזקה)
מעלה מספר בחזקה
סדר פעולות
כפל וחילוק מחושבים לפני חיבור וחיסור, אלא אם יש סוגריים
פונקציה (function) / def
קבוצת הוראות ארוזה תחת שם, שניתן להריץ בקריאה אחת; def היא מילת המפתח שבה מגדירים אותה
