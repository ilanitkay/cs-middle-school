תבנית המונה (Counter)

מונה הוא משתנה שסופר כמה פעמים תנאי מסוים התקיים — הוא מאותחל ל-0 לפני הלולאה, ובכל פעם שהתנאי מתקיים מוסיפים לו 1 (ולא את הערך עצמו, כמו בצובר).

דוגמה — כמה ציונים היו מעל 80 
count = 0
for i in range(10):
    grade = int(input("Grade: "))
    if grade > 80:
        count = count + 1
print("Number of grades above 80:", count)

צובר ומונה יחד

שילוב נפוץ מאוד: לצבור סכום ובמקביל לספור כמה ערכים נצברו, כדי לחשב בסוף ממוצע:

total = 0
count = 0
grade = int(input("Grade (negative number to finish): "))
while grade >= 0:
    total = total + grade
    count = count + 1
    grade = int(input("Grade (negative number to finish): "))
if count > 0:
    print("Average:", total / count)

שימו לב לבדיקה if count > 0 בסוף — היא מונעת חלוקה באפס, למקרה שהמשתמש לא הכניס אף ציון.

מספרים אקראיים

כדי ליצור מספר אקראי, יש לייבא את הספרייה random ולהשתמש בפונקציה randint(a, b), שמחזירה מספר שלם אקראי בטווח מ-a עד b כולל שני הקצוות.

import random

dice = random.randint(1, 6)   # הטלת קובייה - מספר בין 1 ל-6
print("Result:", dice)

מספרים אקראיים שימושיים מאוד למשחקים, הגרלות ותרגילים — ומשולבים היטב עם לולאות: לדוגמה, סימולציה של הטלת קובייה 100 פעמים וספירת התוצאות.

מציאת מינימום / מקסימום

תבנית נפוצה נוספת: לעבור על סדרת ערכים ולמצוא את הגדול/הקטן ביותר מביניהם. הרעיון: שומרים "שיא זמני" במשתנה, ומעדכנים אותו בכל פעם שמוצאים ערך גדול (או קטן) ממנו.

biggest = int(input("First number: "))
for i in range(9):
    num = int(input("Number: "))
    if num > biggest:
        biggest = num
print("Largest:", biggest)

שימו לב שאתחלנו את biggest עם הקלט הראשון ולא עם 0 — כי אם כל המספרים שליליים, אתחול ל-0 היה נותן תשובה שגויה.

מושגי מפתח

מונה (counter)

1מצאו את הטעות

הפעולה הבאה נועדה לקלוט 5 מספרים ולהדפיס את סכומם, אבל נפלה בה טעות לוגית. מהי הטעות, וכיצד יש לתקנה?

def sum_numbers():
    total = 0
    for i in range(5):
        num = int(input("Number: "))
        total = num
    print(total)
הצג תשובה

השורה total = num מחליפה בכל פעם את הערך הקודם ב-total במקום לצבור אליו — כך שבסוף total מכיל רק את המספר האחרון שהוכנס. התיקון: total = total + num (זו בדיוק תבנית הצובר).

2השלימו את הקוד

פעולה שקולטת ציונים עד שמוזן מספר שלילי, וסופרת כמה ציונים היו מעל 90. השלימו את החסר:

count = 0
grade = int(input("Grade (negative to finish): "))
while grade ______ 0:
    if grade > 90:
        count = count ______ 1
    grade = int(input("Grade (negative to finish): "))
print("Number of grades above 90:", count)
הצג תשובה

התנאי בלולאה: grade >= 0 (להמשיך כל עוד הציון לא שלילי). עדכון המונה: count = count + 1.

4פרויקט קטן — משחק ניחוש

כתבו משחק "נחשו את המספר": המחשב בוחר מספר אקראי בין 1 ל-20 (עם random.randint), והשחקן/ית מנסה לנחש. בכל ניחוש שגוי, התכנית תדפיס "too high" או "too low" בהתאם. המשחק נגמר כשמנחשים נכון — והתכנית תדפיס גם כמה ניסיונות היו נדרשים (השתמשו במונה).

הצג פתרון אפשרי 
import random

secret = random.randint(1, 20)
attempts = 0
guess = 0

while guess != secret:
    guess = int(input("Guess a number (1-20): "))
    attempts = attempts + 1
    if guess < secret:
        print("too low")
    elif guess > secret:
        print("too high")

print("Correct! Attempts:", attempts)
