מבני נתונים: tuple, set ותור

⏱ כ-12 שעות לימוד

מה נלמד בפרק הזה

  • להכיר את הטופל (tuple) ולהבין למה הוא "רשימה שלא ניתן לשנות"
  • להשתמש בקבוצה (set) כאוסף בלי כפילויות ובלי סדר
  • להבין את עקרון התור (Queue) — ראשון נכנס, ראשון יוצא
  • לבחור את מבנה הנתונים המתאים לכל בעיה

טופל (tuple) — אוסף קבוע

טופל דומה לרשימה: אוסף מסודר שניגשים אליו לפי אינדקס. ההבדל: טופל לא ניתן לשינוי — אחרי שיצרו אותו אי אפשר להוסיף, להסיר או להחליף איברים. משתמשים בו לנתונים שלא אמורים להשתנות: קואורדינטות, תאריך, צבע RGB.

point = (3, 5)
print(point[0])      # 3
print(len(point))    # 2

# point[0] = 9   ← שגיאה! אי אפשר לשנות טופל

קבוצה (set) — בלי כפילויות

קבוצה היא אוסף לא מסודר שבו כל ערך מופיע פעם אחת בלבד. אין אינדקסים. שימושי כדי להסיר כפילויות, או לבדוק במהירות אם ערך קיים.

nums = {1, 2, 2, 3, 3, 3}
print(nums)            # {1, 2, 3}  — הכפילויות נעלמו

nums.add(4)
nums.discard(1)
print(2 in nums)       # True

# הסרת כפילויות מרשימה:
names = ["a", "b", "a", "c", "b"]
unique = set(names)
print(len(unique))     # 3

תור (Queue) — ראשון נכנס, ראשון יוצא

תור מתנהג כמו תור בסופר: מי שנכנס ראשון — יוצא ראשון (FIFO — First In, First Out). מוסיפים בסוף, מוציאים מההתחלה. משתמשים בתור לניהול "משימות שממתינות לטיפול" לפי סדר הגעה.

ב-Python אפשר לממש תור בעזרת רשימה: append להוספה בסוף, ו-pop(0) להוצאה מהראש.

queue = []
queue.append("A")      # נכנס
queue.append("B")
queue.append("C")

first = queue.pop(0)   # יוצא "A" — הראשון שנכנס
print(first)          # A
print(queue)          # ['B', 'C']

(לתור יעיל יותר קיים גם deque מהמודול collections, אבל לצרכינו רשימה מספיקה.)

איזה מבנה לבחור?

list
אוסף מסודר שצריך לשנות — להוסיף, להסיר, לסדר
tuple
אוסף מסודר שאסור שישתנה — קואורדינטה, תאריך
set
כשחשוב שלא יהיו כפילויות, והסדר לא משנה
Queue
כשצריך לטפל בפריטים לפי סדר הגעה (ראשון נכנס — ראשון יוצא)

מושגי מפתח

tuple (טופל)
אוסף מסודר שלא ניתן לשינוי אחרי היצירה; נכתב בסוגריים עגולים
set (קבוצה)
אוסף לא מסודר בלי כפילויות; נכתב בסוגריים מסולסלים
add / discard
הוספה והסרה של איבר מקבוצה
Queue (תור)
מבנה FIFO — ההוספה בקצה אחד וההוצאה בקצה השני
FIFO
First In, First Out — הראשון שנכנס הוא הראשון שיוצא
ניתן לשינוי / לא ניתן לשינוי
list ו-set ניתנים לשינוי; tuple ומחרוזת לא

4איזה מבנה?

לכל מקרה, כתבו איזה מבנה נתונים מתאים: (א) רשימת המתנה לרופא לפי סדר הגעה. (ב) קואורדינטת נקודה על מפה. (ג) אוסף כל האותיות השונות שמופיעות במשפט.

הצג תשובה

(א) תור (Queue). (ב) טופל (tuple). (ג) קבוצה (set).

6נכון / לא נכון

קבעו נכון או לא נכון: (א) "אפשר לגשת לאיבר בקבוצה לפי אינדקס, כמו ב-set[0]." (ב) "טופל מהיר יותר להגנה מפני שינוי בטעות מאשר רשימה."

הצג תשובה

(א) לא נכון — לקבוצה אין סדר ואין אינדקסים. (ב) נכון — הבחירה בטופל מונעת שינוי בטעות של נתונים שאמורים להישאר קבועים.

7כתבו תוכנית

קלטו משפט מהמשתמש והדפיסו כמה אותיות שונות יש בו (התעלמו מרווחים).

הצג פתרון אפשרי
sentence = input("Enter a sentence: ")
letters = set()
for ch in sentence:
    if ch != " ":
        letters.add(ch)
print(len(letters))
8פרויקט קטן — תור הדפסה

ממשו "תור הדפסה": המשתמש מקליד שמות קבצים עד שמקליד מחרוזת ריקה, כל שם נכנס לתור. אחר כך התכנית מדפיסה "Printing: <name>" עבור כל קובץ, לפי סדר ההכנסה, עד שהתור מתרוקן.

הצג פתרון אפשרי
queue = []

name = input("File name (empty to start printing): ")
while name != "":
    queue.append(name)
    name = input("File name (empty to start printing): ")

while len(queue) > 0:
    current = queue.pop(0)
    print("Printing:", current)
