עבודה עם קבצים

⏱ כ-12 שעות לימוד

מה נלמד בפרק הזה

  • לפתוח קובץ טקסט עם open ולסגור אותו עם close
  • להכיר את מצבי הפתיחה: קריאה ("r"), כתיבה ("w") והוספה ("a")
  • לקרוא קובץ שורה-שורה בלולאה, ולנקות תו ירידת שורה עם strip
  • לכתוב מידע לקובץ
  • לחבר הכול לפרויקט מסכם שקורא, מעבד ושומר נתונים

למה בכלל קבצים?

עד עכשיו כל המידע בתכניות שלנו נעלם ברגע שהתכנית נסגרה. קובץ מאפשר לשמור מידע על הדיסק, כך שאפשר לקרוא אותו שוב בהרצה הבאה — רשימת משתמשים, תוצאות משחק, טקסט לעיבוד.

פתיחה, עבודה, סגירה

העבודה עם קובץ תמיד בשלושה שלבים: פותחים את הקובץ ומקבלים "ידית" (משתנה קובץ), עובדים איתו (קוראים או כותבים), וסוגרים כדי לשחרר אותו ולוודא שהכול נשמר.

מצבי פתיחה

"r" — קריאה
ברירת המחדל. קוראים מהקובץ. אם הקובץ לא קיים — שגיאה.
"w" — כתיבה
יוצר קובץ חדש, או מוחק את התוכן הקיים וכותב מחדש.
"a" — הוספה
כותב בסוף הקובץ בלי למחוק את מה שכבר בו.

קריאת קובץ שורה-שורה

הדרך הנוחה לקרוא קובץ טקסט היא לעבור עליו בלולאת for — כל חזרה נותנת שורה אחת. לכל שורה יש בסוף תו ירידת שורה (\n), ומסירים אותו עם strip.

f = open("names.txt", "r")
for line in f:
    clean = line.strip()
    print("Hello,", clean)
f.close()

כתיבה לקובץ

f = open("results.txt", "w")
f.write("Game 1: 85\n")
f.write("Game 2: 92\n")
f.close()

# הוספה בסוף בלי למחוק:
f = open("results.txt", "a")
f.write("Game 3: 78\n")
f.close()

שימו לב: write לא מוסיף ירידת שורה לבד — צריך לכתוב \n במפורש בסוף כל שורה.

פתיחה בטוחה עם with

קל לשכוח close(). הצורה with סוגרת את הקובץ אוטומטית בסיום הבלוק, גם אם קרתה שגיאה:

with open("names.txt", "r") as f:
    for line in f:
        print(line.strip())
# כאן הקובץ כבר סגור

מושגי מפתח

open
פותח קובץ ומחזיר משתנה קובץ לעבודה איתו
close
סוגר את הקובץ ומוודא שכל מה שנכתב אכן נשמר
מצב "r" / "w" / "a"
קריאה / כתיבה (מוחק קיים) / הוספה בסוף
strip
מסיר רווחים ותו ירידת שורה מתחילת וסוף מחרוזת
write
כותב מחרוזת לקובץ; לא מוסיף \n לבד
with open(...) as f

1שאלת הבנה

מה ההבדל בין פתיחת קובץ במצב "w" לבין מצב "a"?

הצג תשובה

"w" מוחק את כל התוכן הקיים בקובץ וכותב מחדש; "a" משאיר את התוכן הקיים ומוסיף בסופו.

2מצאו את הטעות

הקובץ נכתב, אבל כשפותחים אותו הוא ריק או חסר. מה כנראה חסר בקוד?

f = open("data.txt", "w")
f.write("hello")
הצג תשובה

חסר f.close(). בלי לסגור את הקובץ, ייתכן שמה שנכתב לא נשמר לדיסק.

3עקבו אחר הקוד

הקובץ nums.txt מכיל את השורות 3, 5, 2. מה יודפס?

total = 0
with open("nums.txt", "r") as f:
    for line in f:
        total = total + int(line.strip())
print(total)
הצג תשובה

10

4שאלת הבנה

למה משתמשים ב-line.strip() כשקוראים קובץ שורה-שורה?

הצג תשובה

כל שורה שנקראת מהקובץ כוללת בסוף תו ירידת שורה (\n), ולפעמים רווחים. strip מנקה אותם כדי שנוכל לעבוד עם הטקסט "הנקי" — למשל להשוות אותו או להמיר למספר.

5נכון / לא נכון

קבעו נכון או לא נכון: (א) "write מוסיף ירידת שורה אוטומטית אחרי כל קריאה." (ב) "with open(...) סוגר את הקובץ לבד."

הצג תשובה

(א) לא נכון — צריך לכתוב \n במפורש. (ב) נכון.

6כתבו תוכנית

הקובץ names.txt מכיל שם בכל שורה. כתבו קוד שמדפיס כמה שמות יש בקובץ.

הצג פתרון אפשרי
count = 0
with open("names.txt", "r") as f:
    for line in f:
        if line.strip() != "":
            count = count + 1
print(count)
7כתבו תוכנית

קלטו מהמשתמש שמות עד שמקלידים מחרוזת ריקה, ושמרו כל שם בשורה נפרדת בקובץ guests.txt.

הצג פתרון אפשרי
with open("guests.txt", "w") as f:

    while name != "":
        f.write(name + "\n")
        name = input("Name (empty to stop): ")
8פרויקט מסכם — ניתוח ציונים

הקובץ grades.txt מכיל ציון (מספר שלם) בכל שורה. כתבו תכנית ש:

  1. קוראת את כל הציונים לרשימה
  2. מחשבת ממוצע, ציון מקסימלי וציון מינימלי
  3. סופרת כמה תלמידים מתחת ל-60
  4. כותבת את הסיכום לקובץ חדש summary.txt
הצג פתרון אפשרי
grades = []
with open("grades.txt", "r") as f:
    for line in f:
        if line.strip() != "":
            grades.append(int(line.strip()))

average = sum(grades) / len(grades)

failing = 0
for g in grades:
    if g < 60:
        failing = failing + 1

with open("summary.txt", "w") as out:
    out.write("Average: " + str(average) + "\n")
    out.write("Max: " + str(max(grades)) + "\n")
    out.write("Min: " + str(min(grades)) + "\n")
    out.write("Failing: " + str(failing) + "\n")
