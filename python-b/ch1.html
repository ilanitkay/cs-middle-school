מה נלמד בפרק הזה

  • לזהות מתי מספר החזרות ידוע מראש ומתי הוא תלוי בתנאי
  • לכתוב לולאת for עם range, כולל התחלה, סוף וצעד
  • לכתוב לולאת while עם תנאי עצירה נכון, ולהימנע מלולאה אינסופית
  • לשלב לולאה עם קלט מהמשתמש ועם תבנית צבירה (סכום / מונה)

שני סוגי לולאות — ומתי כל אחת

לולאה מריצה קטע קוד שוב ושוב. ההבדל המרכזי בין שתי הלולאות ב-Python הוא איך יודעים מתי לעצור:

  • לולאת for — כשמספר החזרות ידוע מראש: "חזור 10 פעמים", "עבור על כל תו במחרוזת".
  • לולאת while — כשמספר החזרות לא ידוע מראש ותלוי בתנאי: "כל עוד המשתמש לא הקליד 0", "כל עוד לא ניחשנו את המספר".

לולאת for ו-range

הפונקציה range מייצרת סדרת מספרים שהלולאה עוברת עליהם. יש לה שלוש צורות:

דוגמה — שלוש הצורות של range 
# range(stop): מ-0 עד stop (לא כולל)
for i in range(5):
    print(i)            # 0 1 2 3 4

# range(start, stop): מ-start עד stop (לא כולל)
for i in range(2, 6):
    print(i)            # 2 3 4 5

# range(start, stop, step): עם קפיצות
for i in range(0, 20, 5):
    print(i)            # 0 5 10 15

אפשר גם צעד שלילי כדי לספור אחורה: range(10, 0, -1) נותן 10, 9, 8, ... , 1.

לולאת while ותנאי עצירה

לולאת while חוזרת כל עוד תנאי מסוים מתקיים. חובה לדאוג שמשהו בגוף הלולאה יקדם את התנאי לכיוון עצירה — אחרת הלולאה תרוץ לנצח (לולאה אינסופית).

דוגמה — קליטת מספרים עד שמכניסים 0 
total = 0
number = int(input("Enter a number (0 to stop): "))

while number != 0:
    total = total + number           # צובר את הסכום
    number = int(input("Enter a number (0 to stop): "))

print("Sum:", total)

שימו לב לשתי השורות עם input: אחת לפני הלולאה (כדי שיהיה ערך ראשון לבדוק) ואחת בסוף גוף הלולאה (כדי לקדם לערך הבא). זו תבנית קבועה בלולאות while שקולטות קלט.

for או while — אותה משימה, שתי דרכים

הדפסת המספרים 1 עד 5. כאן מספר החזרות ידוע, אז for טבעי יותר — אבל אפשר גם while:

# עם for
for i in range(1, 6):
    print(i)

# עם while — צריך לנהל את המונה ידנית
i = 1
while i <= 5:
    print(i)
    i = i + 1

בגרסת ה-while אנחנו אחראים על שלושה דברים: לאתחל את i לפני הלולאה, לבדוק אותו בתנאי, ולקדם אותו בגוף. אם שוכחים את i = i + 1 — נקבל לולאה אינסופית.

מושגי מפתח

לולאת for
לולאה שרצה מספר פעמים ידוע מראש, בדרך כלל עם range
range(start, stop, step)
סדרת מספרים מ-start עד stop (לא כולל), בקפיצות של step
לולאת while
לולאה שרצה כל עוד תנאי מתקיים; מספר החזרות לא ידוע מראש
תנאי עצירה
הביטוי הבוליאני של while; כשהוא הופך ל-False הלולאה נעצרת
לולאה אינסופית
לולאה שתנאי העצירה שלה לעולם לא מתקיים, והיא לא נגמרת
תבנית צבירה
משתנה שמאותחל לפני הלולאה ומתעדכן בכל חזרה (סכום, מונה)

8כתבו תוכנית

כתבו תכנית שקולטת מספרים מהמשתמש עד שמקלידים -1, ובסוף מדפיסה כמה מספרים חיוביים הוקלדו.

הצג פתרון אפשרי
count = 0
num = int(input("Enter a number (-1 to stop): "))

while num != -1:
    if num > 0:
        count = count + 1
    num = int(input("Enter a number (-1 to stop): "))

print("Positive numbers:", count)
9כתבו תוכנית

כתבו תכנית שמגרילה מספר סודי בין 1 ל-50 (random.randint(1, 50)), וחוזרת לבקש ניחוש מהמשתמש עד שהוא צודק. בכל ניחוש הדפיסו "Too high" או "Too low", ובסוף כמה ניחושים נדרשו.

הצג פתרון אפשרי
import random

secret = random.randint(1, 50)
guesses = 0
guess = 0

while guess != secret:
    guess = int(input("Your guess: "))
    guesses = guesses + 1
    if guess > secret:
        print("Too high")
    elif guess < secret:
        print("Too low")

print("Correct! Guesses:", guesses)
