פונקציות

⏱ כ-6 שעות לימוד
סרטון: פונקציות בפייתוןהגדרה, זימון ומה קורה בזמן הריצה

מה נלמד בפרק הזה

  • לפרק בעיה גדולה לתת-משימות, ולתכנן פתרון בשיטת top-down
  • לכתוב פונקציה עם פרמטרים ולזמן אותה עם ערכים שונים
  • להשתמש ב-return כדי שפונקציה תחזיר ערך לשימוש בהמשך התכנית
  • להבין את ההבדל בין משתנה מקומי לגלובלי, ומתי צריך global

לפרק בעיה לתת-משימות

כשבעיה גדולה מדי כדי לפתור אותה "בבת אחת", מפרקים אותה לתת-משימות קטנות שכל אחת מהן קלה לפתרון. לכל תת-משימה כותבים פונקציה נפרדת, ואז מחברים את הפונקציות יחד. השיטה הזו נקראת תכנון top-down — מלמעלה (הבעיה הכללית) למטה (הפרטים).

לדוגמה, "בדוק אם מילה היא פלינדרום" מתפרקת ל: (1) להפוך את המילה, (2) להשוות למקור. כל שלב — פונקציה.

פונקציה שמחזירה ערך — return

בחלק א׳ הפונקציות שלנו רק הדפיסו תוצאה. עכשיו נלמד שפונקציה יכולה להחזיר ערך בעזרת return, כך שהתכנית תוכל להמשיך לעבוד איתו — לשמור אותו במשתנה, להשתמש בו בחישוב, או להעביר לפונקציה אחרת.

דוגמה — הפרש בין print ל-return 
def square_print(n):
    print(n * n)          # רק מציג — לא מחזיר כלום

def square(n):
    return n * n           # מחזיר את הערך לקוד שקרא לפונקציה

result = square(5)         # result מקבל 25
print(result + 1)          # 26 — אפשר להמשיך לחשב

square_print(5)           # מדפיס 25, אבל square_print(5) עצמו שווה None

ברגע ש-Python מגיעה ל-return, הפונקציה מסתיימת מיד והשליטה חוזרת לשורה שקראה לה, עם הערך המוחזר.

משתנה מקומי לעומת גלובלי

משתנה שנוצר בתוך פונקציה הוא מקומי — קיים רק בזמן ריצת הפונקציה, ולא נגיש מבחוץ. משתנה שהוגדר מחוץ לכל פונקציה הוא גלובלי, ואפשר לקרוא את ערכו מכל מקום.

כדי שפונקציה תשנה משתנה גלובלי (ולא רק תקרא אותו), צריך להצהיר עליו עם global:

score = 0              # משתנה גלובלי

def add_point():
    global score
    score = score + 1

add_point()
add_point()
print(score)          # 2

בדרך כלל עדיף להעביר מידע לפונקציה דרך פרמטרים ולקבל אותו חזרה דרך return, ולהשתמש ב-global רק כשאין ברירה — קוד שמסתמך על משתנים גלובליים קשה יותר למעקב.

כתבו פונקציה is_even(n) שמחזירה True אם n זוגי ו-False אחרת. השתמשו בה כדי להדפיס את כל המספרים הזוגיים מ-1 עד 20.

    if is_even(i):
        print(i)
8כתבו תוכנית

כתבו פונקציה average(a, b, c) שמחזירה את הממוצע של שלושה מספרים. קראו לה עם 3 מספרים שהמשתמש מקליד, והדפיסו את התוצאה.

הצג פתרון אפשרי
def average(a, b, c):
    return (a + b + c) / 3

x = int(input("First: "))
y = int(input("Second: "))
z = int(input("Third: "))

9פירוק לתת-משימות

כתבו פונקציה reverse_word(word) שמחזירה מחרוזת הפוכה, ופונקציה is_palindrome(word) שמשתמשת בה ומחזירה True/False. הדפיסו בדיקה עבור "level" ועבור "python".

הצג פתרון אפשרי
def reverse_word(word):
    return word[::-1]

def is_palindrome(word):
    return word == reverse_word(word)

print(is_palindrome("level"))    # True
print(is_palindrome("python"))   # False

הערה: את [::-1] נלמד לעומק בפרק המחרוזות הבא.
