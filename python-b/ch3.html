אינדקסים — גישה לתו בודד

כל תו במחרוזת יושב במקום ממוספר. הספירה מתחילה מ-0 משמאל. אפשר גם לספור מהסוף אחורה עם מספרים שליליים: -1 הוא התו האחרון.

s = "Python"
print(s[0])       # P
print(s[-1])      # n
print(len(s))     # 6

Slicing — חיתוך תת-מחרוזת

הצורה s[start:end:step] מחזירה חלק מהמחרוזת: מ-start ועד end לא כולל, בקפיצות של step. כל חלק הוא רשות — s[2:], s[:4], s[::2].

s = "programming"
print(s[0:4])     # prog
print(s[4:])      # ramming
print(s[::2])     # pormig
print(s[::-1])    # gnimmargorp  (מחרוזת הפוכה)

אופרטורים על מחרוזות

print("ab" + "cd")      # abcd  (שרשור)
print("ha" * 3)         # hahaha  (שכפול)
print("y" in "Python")   # True  (בדיקת הכלה)

פעולות מובנות

למחרוזת יש פעולות מובנות שקוראים להן עם נקודה: text.upper(). הן מחזירות מחרוזת חדשה ולא משנות את המקור (מחרוזת ב-Python לא ניתנת לשינוי).

t = "Hello World"
print(t.upper())          # HELLO WORLD
print(t.lower())          # hello world
print(t.find("World"))    # 6   (האינדקס שבו מתחיל; -1 אם לא נמצא)
print(t.replace("World", "Python"))   # Hello Python
print(t.count("l"))       # 3
print(t.split(" "))      # ['Hello', 'World']
print("-".join(["a", "b", "c"]))   # a-b-c

מעבר על תווים בלולאה

לולאת for יכולה לעבור ישירות על תווי מחרוזת:

word = "radar"
count = 0
for ch in word:
    if ch == "r":
        count = count + 1
print(count)              # 2

מושגי מפתח

אינדקס
מספר המיקום של תו במחרוזת; מתחיל מ-0, ושלילי סופר מהסוף
slicing
חיתוך תת-מחרוזת בצורה [start:end:step]; end לא נכלל
len
פונקציה שמחזירה את מספר התווים במחרוזת
in
אופרטור שבודק אם תת-מחרוזת מופיעה בתוך מחרוזת
find
מחזיר את האינדקס של המופע הראשון, או -1 אם לא נמצא
split / join
split מפצל מחרוזת לרשימה; join מחבר רשימה למחרוזת אחת
מחרוזת לא ניתנת לשינוי
פעולות כמו replace מחזירות מחרוזת חדשה, לא משנות את המקור

6מצאו את הטעות

הקוד אמור להפוך את המחרוזת לאותיות גדולות, אבל ההדפסה מציגה hello. מדוע?

s = "hello"
s.upper()
print(s)

7כתבו תוכנית

קלטו מחרוזת מהמשתמש והדפיסו כמה אותיות "e" יש בה — פעם אחת עם לולאה על התווים, ופעם אחת עם count.

הצג פתרון אפשרי
text = input("Enter text: ")

count = 0
for ch in text:
    if ch == "e":
        count = count + 1
print(count)

print(text.count("e"))
8כתבו תוכנית

כתבו פונקציה is_palindrome(word) שמחזירה True אם המילה נקראת אותו דבר משני הכיוונים. השתמשו ב-slicing.

הצג פתרון אפשרי
def is_palindrome(word):
    return word == word[::-1]

print(is_palindrome("level"))   # True
print(is_palindrome("hello"))   # False
