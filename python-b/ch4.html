רשימות (list)

⏱ כ-8 שעות לימוד
סרטון: רשימה (List)מבנה נתונים שמכיל יותר מערך אחד

מה נלמד בפרק הזה

  • ליצור רשימה ולגשת לאיבר לפי אינדקס (כולל שלילי)
  • לשנות רשימה: append, insert, pop, remove
  • לסדר ולהפוך רשימה: sort, reverse, ולספור עם count
  • לעבור על רשימה בלולאה ולחשב עליה (סכום, ממוצע, מקסימום)
  • להכיר רשימה דו-ממדית (רשימה של רשימות)

מה זו רשימה?

רשימה היא מבנה נתונים שמכיל אוסף מסודר של ערכים, תחת שם אחד. בניגוד למחרוזת — רשימה כן ניתנת לשינוי: אפשר להוסיף, להסיר ולהחליף איברים. הערכים יכולים להיות מכל סוג, ואפילו מעורבים.

scores = [80, 92, 75, 88]
print(scores[0])       # 80
print(scores[-1])      # 88
print(len(scores))   # 4
scores[2] = 100        # החלפת איבר

פעולות שמשנות את הרשימה

fruits = ["apple", "banana"]
fruits.append("cherry")      # ['apple', 'banana', 'cherry']
fruits.insert(1, "kiwi")      # ['apple', 'kiwi', 'banana', 'cherry']
fruits.remove("banana")        # מסיר לפי ערך
last = fruits.pop()             # מסיר ומחזיר את האחרון
print(fruits, last)

סידור, היפוך וספירה

nums = [4, 1, 7, 1, 3]
nums.sort()          # [1, 1, 3, 4, 7]
nums.reverse()       # [7, 4, 3, 1, 1]
print(nums.count(1))   # 2

לולאה על רשימה וחישובים

grades = [70, 85, 90, 60]

total = 0
for g in grades:
    total = total + g

print("Sum:", total)
print("Average:", total / len(grades))
print("Max:", max(grades))
print("Min:", min(grades))

רשימה דו-ממדית

איבר ברשימה יכול בעצמו להיות רשימה — כך בונים טבלה. פונים לתא עם שני אינדקסים: table[שורה][עמודה].

table = [[1, 2, 3],
         [4, 5, 6]]

print(table[0][2])   # 3
print(table[1][0])   # 4

מושגי מפתח

רשימה (list)

append / insert

pop / remove
pop מסיר לפי אינדקס ומחזיר את הערך; remove מסיר לפי ערך
sort / reverse
sort מסדר את הרשימה במקום; reverse הופך את הסדר
max / min / len
פונקציות מובנות: הגדול, הקטן, ומספר האיברים
רשימה דו-ממדית
רשימה שאיבריה רשימות; פונים אליה בשני אינדקסים

9כתבו תוכנית

כתבו פונקציה above_average(nums) שמחזירה רשימה חדשה עם כל המספרים שגדולים מהממוצע של nums.

הצג פתרון אפשרי
def above_average(nums):
    avg = sum(nums) / len(nums)
    result = []
    for n in nums:
        if n > avg:
            result.append(n)
    return result

print(above_average([10, 20, 30, 40]))   # [30, 40]
